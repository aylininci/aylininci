# Aylin İnci — Kişisel Site

SEO ve web geliştirme üzerine yetkinliklerin ve saha notlarının paylaşıldığı iki dilli (TR/EN) tek sayfa site. Açık/koyu tema desteklidir.

## Klasör içeriği
- `index.html` — sitenin tamamı (tek dosya)
- `aylin-inci-logo.png` — header ve footer logosu
- `favicon.png` — sekme ikonu
- `.nojekyll` — GitHub Pages'in dosyaları olduğu gibi yayınlaması için

## GitHub Pages'te yayınlama
1. Yeni bir repo oluştur (ör. `kullaniciadin.github.io` veya herhangi bir isim).
2. Bu klasördeki tüm dosyaları reponun köküne yükle.
3. Repo → **Settings → Pages** → *Source: Deploy from a branch* → **main / (root)** seç.
4. Birkaç dakika içinde site `https://kullaniciadin.github.io/repo-adi/` adresinde yayına girer.
5. Özel alan adı kullanacaksan **Settings → Pages → Custom domain** alanına ekle; repoya bir `CNAME` dosyası oluşturulur.

## Yayına almadan önce güncellenecekler
- **E-posta:** `index.html` içinde `merhaba@aylininci.com` geçen yeri kendi adresinle değiştir (form gönderiminde kullanılıyor).
- **LinkedIn:** `https://www.linkedin.com/` geçen iki yeri kendi profil adresinle değiştir.
- **Özgeçmiş:** Header'daki "Özgeçmiş" butonu `aylin-inci-cv.pdf` dosyasını açar. CV'ni bu isimle klasöre eklersen buton çalışır; eklemezsen butonu kaldırabilir veya linkini değiştirebilirsin.

## Notlar
- İletişim formu, ziyaretçinin kendi e-posta uygulamasını açar (mailto). Mesajın uygulama açmadan doğrudan kutuna düşmesini istersen Formspree gibi ücretsiz bir servise geçebiliriz.
- Rehber bölümündeki kartlar şimdilik "Yakında" olarak duruyor; yazıları yayınladıkça bu kartları gerçek bağlantılarla güncelleyebilirsin.
